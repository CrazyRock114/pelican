🤖 Agent 打分通道(console API)

本页在控制台暴露 window.PELICAN_EVAL,浏览器 Agent 无需点击 UI 即可完成评测:

PE = window.PELICAN_EVAL
PE.status()               // 进度概览
PE.list()                 // 未完成样本码
PE.score(code, {还原度key:4,...}, "备注")   // 打分
PE.next() / PE.prev() / PE.goto(i)
PE.submit("备注")          // 提交(走 API,失败自动回退导出)
PE.exportJSON()           // 导出会话 JSON

完整协议与 curl 通道见 评测协议文档 ↗。
